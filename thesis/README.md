## 学校要求与暂行排版

本次核实到的公开依据为长春大学教务处《关于做好2024届本科生毕业设计（论文）工作的通知》，发布于2023年12月6日。通知要求封面、标题、中英文摘要、目录、正文、致谢和参考文献；理工类论文全文不少于1.5万字。设计类另有说明书字数和图纸要求，软件课题的归档分类由学院或导师确认。

截至本次核查，未取得本届计算机专业正文模板。当前A4、宋体小四、20磅行距、黑体标题、摘要目录罗马页码及正文阿拉伯页码均为暂行排版，不能称为本届校方规定。2024材料包的过程手册格式不等于论文正文模板。取得本届模板后应统一校准样式，并重新导出和检查PDF。

`evidence/manuscript-counts.json` 中的汉字数和字符数由脚本按明确规则统计，仅供编辑检查，不替代学校或Word的最终字数口径。签名、诚信声明和查重材料应按当届要求由作者本人办理。

## 复现入口

附录A列出Go、Maven和Compose命令。服务夹具使用可丢弃资源，运行前应查看 `compose.experiments.yml` 与 `smoke/experiments/verify.py`。固定源码起点、后端版本、配置及验收命令，再解释逐Run结果。

合成机制检查可以运行：

```powershell
powershell -File thesis/tools/run_mechanism_bench.ps1 -Go '实际的go.exe绝对路径'
```

该脚本暂时创建独立命令目录，结束后删除自己创建的目录；默认使用仓库的 `.tools/go/bin/go.exe`。它不调用真实模型。重新运行会覆盖机制结果，故应另存旧证据，并同步更新证据哈希。

文档构建需要Python的 `python-docx`、`markdown-it-py` 和Pillow。先运行 `thesis/tools/make_figures.py` 与 `thesis/tools/build_thesis.py`，再运行 `thesis/tools/export_with_word.ps1`。当前Windows导出脚本使用已安装的Microsoft Word，更新目录和分节页码并生成PDF；没有Word的环境需另选受支持的渲染工具。每次更改排版后应将PDF渲染成页面图片并逐页检查。

公开存档没有包含完整个人对话历史、带环境信息的原始Surefire XML或数据库凭据。历史记录和原始学校附件只在本地用于需求、来源与格式核查。
