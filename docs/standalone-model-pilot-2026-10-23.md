# 独立桌面版真实模型试验（2026-10-23）

本次试验使用实际配置的 `gpt-6-sol`，通过独立版控制面和 Agent Runner 发起真实模型请求。仅使用临时生成的代码夹具，不涉及个人项目、文稿或凭据。协议、API Key 和供应商地址不写入公开记录。

## 验收条件

- CHAT：计算 17 + 25，验收答案 42。
- PLAN：只读检查一个错误的 JavaScript clamp 函数，解释错误，不写文件或运行命令。
- CODE：修正 clamp 实现，不修改测试；审批工具调用后运行测试，再由测试程序独立应用任务补丁并执行 5 个范围内、范围外和边界断言。

## 结果

| 场景 | 首轮连续场景 | 独立代码场景 | 第二轮连续场景 |
| --- | --- | --- | --- |
| CHAT | 通过，4.192 秒 | 未运行 | 通过，3.101 秒 |
| PLAN | 通过，20.845 秒 | 未运行 | 通过，18.361 秒 |
| CODE | 未通过，21.768 秒 | 通过，19.912 秒 | 通过，21.200 秒 |

7 次任务中 6 次达到验收条件。首轮 CODE 调用了 1 次工具，没有进入审批；原始试验程序当时没有保存足以定位原因的错误诊断，因此不能断言失败原因。后续试验补充了脱敏错误采集与工具事件计数，没有修改生产实现。

独立 CODE 使用新的项目和对话，第二轮则重新执行 CHAT → PLAN → CODE。两次成功的 CODE 都经过 2 次工具审批，补丁被独立应用后通过全部 5 项断言。工具调用次数分别为 5 和 3。

## 范围与复现

这是一次真实集成试验，样本很小，不能用于估计总体成功率、复杂仓库任务表现或长期可靠性。保留失败结果，不采用只报告最后一次成功的方式。协议夹具的稳定性测试与该模型试验分别统计。

测试入口为 `desktop/native/standalone_live_test.go`。提供实际模型配置并显式启用 `PROOFCODE_LIVE_MODEL_EVAL=1` 后，运行 `go test ./... -run TestStandaloneLiveModelTasks -count=1 -v`。通过 `PROOFCODE_STANDALONE_TEST_BUNDLE` 指向已准备的独立运行目录；`PROOFCODE_LIVE_MODEL_REPORT` 可指定本机私有报告路径，`PROOFCODE_LIVE_MODEL_CASES` 可选择 CHAT、PLAN、CODE。实际配置变量以测试文件中的入口检查为准。自动审批仅针对该测试生成的临时夹具中的补丁和测试命令。
