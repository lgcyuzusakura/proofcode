# 账户与模型配置验收（2026-10-12）

本次在 `codex/compact-context-agent-tools` 工作树和隔离的 `proofcode-experiments` Docker 栈验证。未调用图片生成或付费模型。浏览器使用 `localhost:15175` 的独立登录源，保留 `127.0.0.1:15175` 中用户原有登录状态。

## 功能与边界

- 注册、密码登录、账户信息、登出、失效会话回到登录页；迟到的旧请求不能清除新会话。已打开的任务 WebSocket 在后续发送前重新校验会话和工程归属。
- 工程与模型服务按账户隔离；首个账户认领未归属旧工程，升级时已存在唯一账户的可在下一次成功登录补全归属。多个账户时不自动认领。
- 网页保存模型服务名称、Base URL、API Key、Responses/Chat 协议。密钥加密保存且不回显；更换地址要求重新输入密钥。任务保存加密配置快照，Runner 仅凭有效任务租约读取。
- 服务通过 OpenAI 格式 `/models` 读取模型目录，对话使用模型下拉列表；模型显示名可保存，空显示名回退到模型 ID。未保存改动时禁用目录刷新，避免请求旧地址。
- 默认拒绝私有及特殊网络地址；实验栈显式允许本地模拟服务。生产 Compose 提供管理员环境开关。只提供 Anthropic Messages 的服务不在本轮支持范围。

## 实际浏览器验收

注册并登录测试账户，保存 Responses 服务，读取到 `fixture-chat` 和 `fixture-only`；密钥输入框保存后清空，显示名称保存后同步到对话下拉列表。

同一持久对话先以 Responses 发送 `PROOFCODE_CHAT_SMOKE FIRST`，再切换 Chat 协议、重新读取目录并发送 `PROOFCODE_CHAT_SMOKE SECOND`。两个回合均成功；模拟服务要求第二回合包含第一回合的完成回复，证明切换协议和重新登录后历史仍可用。

模拟用量分别为 100 输入 / 20 输出；Responses 另报告 75 缓存输入。它们是确定性 fixture 数值，只验证用量解析和展示，不能视为真实模型性能数据。任务仍采用 16k 默认输入、2k 输出和 128k 上限。

390 × 844 窄屏中设置面板宽度 343px，文档宽度 390px，没有横向溢出。账户面板显示正确用户名，退出返回登录页，错误密码得到明确提示，正确密码可恢复原对话。
